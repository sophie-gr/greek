# Ελληνικά: карточки и упражнения

Страница: `index.html`. Словарь: `words.csv`.

## Как добавить слова или новую тему

1. Откройте `words.csv` на GitHub и нажмите на карандаш (Edit).
2. Добавьте строку в формате:

```
тема;слово с артиклем;перевод;мн.ч. с артиклем;пометка
Урок 5 — Цвета;το χρώμα;цвет;τα χρώματα;
```

3. Нажмите **Commit changes**. Через 1–2 минуты слова появятся на странице.

Правила:
- Разделитель — точка с запятой `;`. Внутри перевода используйте запятую, а не `;`.
- Слово пишется **с артиклем** (ο / η / το), по нему страница определяет род.
- Новая тема появляется сама, если в первой колонке написать новое название.
- Колонка «пометка» необязательна. Если в ней есть слово «исключение» или «неправильное», это слово не попадёт в упражнения на род по окончанию и на образование мн. числа.
- Строки, начинающиеся с `#`, игнорируются (можно временно скрыть слово).
