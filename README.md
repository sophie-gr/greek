# Ελληνικά: страницы для учеников

Код страницы общий: `index.html`. Материалы каждого ученика лежат в своей папке `students/<код>/`.
Ссылка для ученика: `https://sophie-gr.github.io/greek/?s=<код>`.
Без `?s=` открывается страница ученика `a1`.

В кодах только латинские буквы, цифры, `-` и `_`, без имён: репозиторий публичный.

## Что лежит в папке ученика

Все файлы необязательны: вкладка появляется, только если для неё есть материал.

| Файл | Вкладки |
|---|---|
| `words.csv` | «Слова» (список, можно распечатать), «Карточки», «Упражнения» |
| `rules.html` | «Правила» |
| `videos.csv` | «Видео» (YouTube встраивается прямо в страницу) |
| `config.json` | настройки: какие вкладки показывать и в каком порядке |

### words.csv

```
тема;слово с артиклем;перевод;мн.ч. с артиклем;пометка;вариант
Урок 5 — Цвета;το χρώμα;цвет;τα χρώματα;;
Семья;ο πατέρας;отец;οι πατέρες;;разг. мн.ч.: οι πατεράδες
```

- Разделитель — `;`. Внутри перевода используйте запятую.
- Слово пишется **с артиклем** (ο / η / το): по нему определяется род.
- Тема создаётся сама, если в первой колонке написать новое название. Новый урок = новые строки, наперёд ничего не видно.
- «пометка»: если в ней есть «исключение» или «неправильное», слово не попадает в упражнения на род по окончанию и на мн. число.
- «вариант»: разговорная или другая форма, на карточке она показывается жёлтой плашкой.
- Тема, начинающаяся со слова «Повторение», не входит в «Все новые».
- Строки, начинающиеся с `#`, скрыты.

### videos.csv

```
урок;название;ссылка;комментарий
Урок 1;Греческий алфавит;https://www.youtube.com/watch?v=XXXXXXXXXXX;посмотреть до урока
```

### config.json

```json
{
  "subtitle": "слова · род · артикли",
  "cheat": true,
  "tabs": ["rules", "list", "cards", "ex", "video"],
  "start": "rules"
}
```

- `tabs`: какие вкладки показывать: `rules` (Правила), `list` (Слова), `cards` (Карточки), `ex` (Упражнения), `video` (Видео).
- `cheat`: показывать ли сверху шпаргалку по окончаниям ο / η / το (включайте после темы «Артикли»).
- `start`: какая вкладка открывается первой.

## Новый ученик

1. Создайте папку `students/<новый код>/` и положите туда хотя бы `words.csv`.
2. Отправьте ученику ссылку `https://sophie-gr.github.io/greek/?s=<новый код>`.
